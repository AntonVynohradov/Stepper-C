
# Modules


Here is a list of all modules:


* [**Build-time configuration**](group__sstep__config.md) _Macros that select the code compiled into the library._ 
    












* [**Definitions**](group__sstep__defs.md) _Constants shared by the public API._ 
    





















* [**Numeric backend**](group__sstep__math.md) _Types and operations that hide whether the library computes in fixed point or in float._ 
    























































* [**Stepper-C API**](group__sstep__api.md) _Initialise a driver, run its loops and command motion._
