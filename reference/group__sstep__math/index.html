    Detailed Description¶

    The control code is written once against these types and operations; the backend is selected at build time with SSTEP_CFG_MATH_BACKEND.

    Per-unit signals. Inside the control loops every electrical signal is normalised to a base value computed by sstep_init(): * current: 1.0 = power stage current full scale (i_full_scale_ma), * voltage: 1.0 = nominal bus voltage (vbus_nominal_mv), * duty cycle: 1.0 = 100 %.

    Both backends therefore see values in about -1..+1, which makes Q15 exact enough and lets the two backends be compared sample by sample in the tests.

    Type Fixed point backend Float backend
    sstep_real_t int16_t, Q15 (1.0 = 32768, range -1 .. +0.99997) float, same range
    sstep_acc_t int32_t, Q15 with 16 integer bits (range +/-65536) float, same range
    sstep_angle_t uint32_t, one electrical turn = 2^32 same
    struct sstep_gain Q15 mantissa and binary exponent float

    Same behaviour in both backends. Every operation saturates to the ranges in the table instead of overflowing, in both backends, so that a test can compare them. Angles wrap by design.

    Speed. The per-sample operations are static inline and branch-light; the fixed point backend uses only 32-bit multiplications (no 64-bit arithmetic), so it suits Cortex-M0. Functions that convert engineering units (*_from_ratio, sstep_real_to_units()) use 64-bit integers and division: call them at initialisation or from the slow loop, not from the fast loop.

    Public Functions Documentation¶

    function sstep_gain_from_ratio¶

    Create a gain equal to num / den. 

    int sstep_gain_from_ratio (
    int32_t num,
    int32_t den,
    struct sstep_gain * gain
)

    Initialisation only (64-bit division).

    Parameters:

    • num Numerator.
    • den Denominator, not 0.
    • gain Result.

    Return value:

    • SSTEP_OK Success.
    • SSTEP_ERR_PARAM gain is NULL, den is 0, or |num / den| rounds above 32767.

    Note:

    Every non-zero int32 ratio is at least 2^-31 and is representable; ratios below 2^-16 lose resolution (the mantissa is no longer normalised).

    function sstep_gain_from_ratio64¶

    Create a gain equal to num / den with 64-bit operands, for gains computed from several engineering values (for example L * wc * I_base / V_base). 

    int sstep_gain_from_ratio64 (
    int64_t num,
    int64_t den,
    struct sstep_gain * gain
)

    Initialisation and slow loop only: at most three 64-bit divisions.

    Parameters:

    • num Numerator, |num| < 2^62.
    • den Denominator, 0 < |den| < 2^62.
    • gain Result.

    Return value:

    • SSTEP_OK (gain NULL, den 0, an operand out of range, or |num / den| rounds above 32767). Ratios below 2^-31 give 0 (fixed point).
