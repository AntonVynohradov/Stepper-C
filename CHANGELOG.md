## [Unreleased]

### Added

- Repository skeleton from the SystemFromScratch® library blueprint (CMake, presets,
  CI workflows, VS Code tasks, documentation site and PDF manual tooling).
- Public API contract (headers only, no implementation yet):
  - `inc/sstep_config.h`: build-time configuration (numeric backend, topologies,
    microstep limit, sine table size, argument checks), each value range-checked;
  - `inc/sstep_defs.h`: status codes, topologies, fault flags, driver states;
  - `inc/sstep_math.h`: backend types (Q15 `int16_t` or `float`), per-unit convention,
    32-bit electrical angle;
  - `inc/sstep_ctrl.h`: configuration structures in integer engineering units, hardware
    callbacks given at initialisation, fast/slow loop functions, motion commands.
- CMake cache variables `SSTEP_MATH_BACKEND` (FIXED/FLOAT) and `SSTEP_CONFIG_DIR`.
- `tests/compile/sstep_api_check.c`: compile check of the API with an example
  configuration (17HS19-2004S1 on B-G431B-ESC1).
- Numeric backend (`inc/sstep_math.h`, `src/sstep_math.c`):
  - saturating `static inline` operations for both backends (add, sub, neg, abs, mul,
    clamp, accumulator add/clamp, gain multiply), identical ranges in both backends;
  - `struct sstep_gain` (Q15 mantissa + exponent, or float) and
    `sstep_gain_from_ratio()`, `sstep_real_from_ratio()`, `sstep_real_to_units()` for
    conversions from engineering units without floating point;
  - `sstep_sin_cos()`: quarter-wave table with linear interpolation; the table
    (`src/sstep_sin_table.c`) is generated by `tools/sstep_gen_sin_table.py`.
- Preset `[UnitTestsFloat]Stepper Motor Control`; `[UnitTests]Stepper Motor Control` builds the fixed point backend.

- Control implementation (both numeric backends):
  - `sstep_init()`: validation of every configuration field, per-unit gains from
    engineering units without floating point (Kp = L wc, Ki = R wc, back-calculation
    Kb = Ts R / L, ADC scaling, back-EMF feed-forward; 2 pi = 710 / 113);
  - fast loop: ADC conversion, overcurrent / overvoltage / undervoltage trips, PI current
    control with Q27 integrators (fixed point) and back-calculation anti-windup, voltage
    drive mode, averaged power stage for two H-bridges and for three legs with a common
    leg (voltage vector scaled with its direction kept, bus voltage compensation);
  - slow loop: integer motion generator (positions in 1/65536 microstep, exact discrete
    braking: no overshoot, exact stop on the target), hold current, events, bus voltage
    scale; angle interpolated in the fast loop;
  - slow -> fast hand-off through a double buffer (no torn reads on a single core);
  - commands: move to / by, run, stop, set position (rotor angle kept), currents,
    motion limits, faults, status.
- `sstep_gain_from_ratio64()` (at most three 64-bit divisions), integrator type
  `sstep_integ_t`, `sstep_gain_mul_acc()`, `sstep_div_unit()`, `sstep_acc_scale()`,
  `sstep_acc_to_ticks()`.
- No dependency on `<string.h>`.

### Quality

- Unit tests `tests/unit/gtest_sstep_math.cpp` (18 tests): 100 % line and branch
  coverage of `src/sstep_math.c` and of the inline operations, in both backends.
- Measured sin/cos error, default table (8 bits): fixed point 1.0 LSB (3.05e-5), float
  4.7e-6.
- Unit tests of the power stage, motion generator, API and closed loop with a motor model
  (`tests/unit/sstep_test_plant.hpp`): 76 tests (fixed point), 75 (float); 100 % line and
  branch coverage of `src/` in both backends (gcov); clean under ASan and UBSan.
- Closed loop against the Scilab prototype (sfs-stepper-sim): current step overshoot
  1.11 %, settling 0.40 ms (prototype 1.12 %, 0.40 ms); 8 rev/s current 1.862 A two
  H-bridges, 1.557 A shared leg (prototype 1.862 / 1.557 A); load angle at 0.25 N*m
  37.21 deg (prototype 37.21 deg).
- Code size (clang -Os, both topologies, sine table included): Cortex-M0+ fixed point
  8.5 kB, Cortex-M4F fixed point 8.2 kB, Cortex-M4F float 9.0 kB.
